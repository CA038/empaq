# EMPAQ Landing Page
Landing page estática, modular y responsive, sin carrito ni pagos.

## Ejecutar
`python3 -m http.server 8000` y abrir `http://localhost:8000`.

## Arquitectura
`index.html` → `js/main.js` → `js/components/*.js`.
`css/main.css` importa hojas por sección. Imágenes en `assets/`.

## Documentación
Leer `docs/DOCUMENTACION.md` antes de modificar el sitio.

Las imágenes de productos son recursos de prototipo extraídos del boceto aprobado; reemplazarlas por fotografías oficiales antes de publicar.
